# Video UTS — Aplikasi Es Teh

Project pembuatan video presentasi UTS (maksimal 10 menit).

- `naskah.md` — naskah narasi per bagian (sesuai Brief UTS)
- `tts/` — pembuat suara narasi gratis (edge TTS, suara `id-ID-GadisNeural`)
- `rekam/` — script Playwright untuk merekam demo dari build web Flutter
- `remotion/` — komposisi video (Remotion 4, React): slide, demo, subtitle

Cara membuat suara: `powershell -ExecutionPolicy Bypass -File .\JALANKAN.ps1`

Video final tidak disimpan di repository (ukuran besar); tautan video dikumpulkan lewat E-Learning.
